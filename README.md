# FLINTA-Stadtkarte-von-Hannover---R-ume-des-Wohlbefindens
Die Karte entstand im Rahmen der Materarbeit XY. Die KArte ist durch den Prozess des Kollaborativen-Countermappings durch eine gemeinsame Umfrage und Kartierung entstanden. Dabei wurden FLINTA* in Hannover befragt was Räume des Wohlbefindens in der Stadt Hannover für sie sind und was diese Räume für sie ausmachen.
